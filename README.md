# README

## Requirements
- Python 3.9+
- Browser cookies from x.com:
  - auth_token
  - ct0

## Run
python twitter_scanario.py `
  --user elonmusk `
  --auth-token "YOUR_AUTH_TOKEN" `
  --ct0 "YOUR_CT0" `
  --out tweets.txt


## Optional
--count 20     # how many tweets
--log run.log  # save debug log
